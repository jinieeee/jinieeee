## 🚀 자기소개
문서화와 아키텍처 개선에 강점이 있는 4년차 웹개발자 이지은입니다.<br>
React, NextJS, TypeScript, Java, Spring boot, PostgreSql, MySql 등 백엔드와 프론트엔드 개발, 운영한 경험이 있습니다. 서버 부하, 보안, 데이터 무결성 등 다양한 운영 이슈를 고려하며 안정성과 확장성을 중점으로 개발하기 위해 노력하고 있습니다. <br>
현재는 (주)플래티어의 솔루션의 고도화와 추가 기능 개발을 담당하고 있습니다.
